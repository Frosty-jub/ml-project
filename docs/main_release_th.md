# การรวมงานคนที่ 6 เข้า main

ผู้ใช้อนุญาตให้ดำเนินการรวมงานเข้า main และตรวจ flow ให้เสร็จเมื่อ 30 กันยายน 2026

## ลำดับการตรวจ

1. ตรวจความต่างระหว่าง integration/real-model-serving กับ main และตรวจ conflict
2. เปลี่ยนปลายทาง PR #7 จาก Dec เป็น main
3. ตรวจ CI ของ PR ที่รวมกับ main ชั่วคราว ต้องผ่านทุกด่านก่อน merge
4. รวมผ่าน PR โดยตรวจว่า head commit ยังเป็นฉบับที่ทดสอบแล้ว
5. ตรวจ GitHub Actions บน main หลัง merge และเก็บ artifact/ผลทดสอบ
6. ตรวจ Airflow DAG ด้วย source ฉบับส่งจริง และบันทึก run ID พร้อมผลแต่ละ task

คำสั่งและผลจริงจะบันทึกในรายงานปิดงาน โดยไม่ใช้การยืนยันของระบบอัตโนมัติแทนการยืนยันจากสมาชิกทีม

## ขอบเขต

- เชื่อมโค้ดข้อมูล โมเดล Registry API และ Monitoring ของทีม
- ใช้ Airflow สำหรับ DAG และ GitHub Actions สำหรับ CI/CD
- CD ส่งมอบ bundle และสาธิต deployment/rollback ใน Docker แยกของ CI
- การยืนยันสัญญาโมเดล/API และ proposed SLO โดยเจ้าของงานยังต้องบันทึกโดยทีม ไม่ถือว่าการ merge เป็นการยืนยันแทนเจ้าของงาน
- ไม่ได้ตั้ง deploy ไป server production ภายนอก เพราะยังไม่มีปลายทางที่ระบุ
