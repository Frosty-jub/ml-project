สร้างผลลัพธ์ด้วย Python 3.12.14, pandas 3.0.1 และ openpyxl 3.1.5 โดยรัน `scripts/prepare_data.py` หลังวาง ZIP และแตก workbook ผ่าน `scripts/download_data.py`

ตรวจตัวอย่าง SKU `10002` ที่ origin `2009-12-01`: target เท่ากับ 143 หน่วย และผลรวมยอดขายรายวันของ 7 วันถัดไปเท่ากับ 143 หน่วย

กฎชุดแรกยังไม่ลบแถวซ้ำหรือรหัสค่าบริการ/ค่าขนส่งอัตโนมัติ ทีมควรทำ EDA และตกลงกฎเหล่านี้ก่อนใช้ข้อมูลฝึกโมเดล
